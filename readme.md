# Riddhi Jain - Personal Portfolio Website

A modern, responsive personal portfolio website showcasing projects, skills, education, hackathons, and certifications.

## 🚀 Overview

- **Author**: Riddhi Jain
- **Role**: B.Tech Student & Aspiring Software Developer
- **Focus**: Programming, Web Development, UI/UX Design, and Software Innovation

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Vanilla CSS, Modern CSS Grid & Flexbox, Custom Design Tokens
- **Icons & Fonts**: Font Awesome 6, Google Fonts (Outfit & Inter)
- **Programming Languages**: Python, C, C++, JavaScript
- **Design Tools**: Figma, UI/UX Wireframing & Prototyping

## ✨ Sections

1. **Home / Hero**: Introduction, social links, resume download, and quick call-to-action buttons.
2. **About**: Personal profile, interests, and key highlight cards (Development, Design, Learning).
3. **Education**: Academic degree, major, and learning journey.
4. **Skills**: Categorized technical skills in Programming, Web Development, Design, and Developer Tools.
5. **Projects**: Dynamically rendered project cards with live demo and source code links.
6. **Hackathons**: Featured hackathon initiatives and technical stack badges.
7. **Certificates**: Verified courses and credentials.
8. **Achievements**: Key milestones across hackathons, certifications, and project deliveries.
9. **Learning Journey**: Timeline tracing technical growth and milestones.
10. **Contact**: Interactive contact form with validation and feedback alerts, along with email/social links.

## 🏃 How to Run Locally

### Option 1: Using Vite (Recommended)
```bash
npm run dev
```
Then open [http://localhost:5173](http://localhost:5173) in your browser.

### Option 2: Using Python HTTP Server
```bash
python -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Direct File Open
Double-click `index.html` or open it in any modern web browser.
